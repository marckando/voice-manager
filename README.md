# Речевой помощник

Учебное приложение Windows Forms на C# и .NET 10.0. Программа распознаёт русскую речь с микрофона, выводит её в текстовое поле и озвучивает введённый пользователем текст. Каждый сеанс сохраняется в отдельный текстовый файл.

## Возможности

- распознавание русской речи с микрофона;
- вывод распознанных фраз в окно программы;
- озвучивание введённого текста установленным русским голосом Windows;
- остановка записи и озвучивания;
- сохранение каждого сеанса в отдельный файл `.txt`;
- автоматическое сохранение активного сеанса при закрытии программы.

Распознавание выполняется локально с помощью Vosk. Звук с микрофона не отправляется на внешний сервер.

## Требования

- Windows 10 или Windows 11, 64-разрядная система;
- Visual Studio 2026 версии 18.0 или новее с компонентом **Разработка классических приложений .NET**;
- установленный .NET 10 SDK;
- микрофон;
- совместимый с `System.Speech` русский голос Windows для озвучивания;
- русская модель Vosk (устанавливается один раз).

## Подготовка модели распознавания

Модель не включена в репозиторий, потому что это отдельный набор данных размером около 45 МБ.

1. Откройте папку проекта.
2. Запустите PowerShell в этой папке.
3. Выполните команду:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\СкачатьМодель.ps1
   ```

4. После завершения в папке `Models` должна появиться папка `vosk-model-small-ru-0.22`.

Скрипт загружает официальную небольшую русскую модель Vosk и распаковывает её автоматически. При ручной загрузке используйте [архив русской модели Vosk](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip) и распакуйте его так, чтобы путь выглядел следующим образом:

```text
РечевойПомощник
└── Models
    └── vosk-model-small-ru-0.22
        ├── am
        ├── conf
        └── ...
```

## Запуск в Visual Studio

1. Откройте файл `РечевойПомощник.sln`.
2. Дождитесь восстановления пакетов NuGet. В проекте используются `NAudio`, `Vosk` и `System.Speech`.
3. Убедитесь, что в списке конфигураций выбрана платформа `x64`.
4. Запустите программу клавишей **F5**.

## Работа с программой

### Распознавание речи

1. Нажмите **«Начать запись»**.
2. Произнесите фразу в микрофон.
3. Нажмите **«Остановить запись»**. Распознанные фразы появятся в верхнем поле.
4. Можно снова начать запись, не завершая текущий сеанс.

### Озвучивание текста

1. Выберите русский голос в списке.
2. Введите текст в нижнее поле.
3. Нажмите **«Озвучить»**.
4. Для остановки нажмите **«Остановить озвучивание»**.

### Сохранение сеанса

Нажмите **«Завершить сеанс и сохранить»**. Программа создаст отдельный файл с датой и временем в имени. Если закрыть окно с незавершённым сеансом, он также будет сохранён автоматически.

Файлы находятся в папке:

```text
Документы\Речевой помощник\Сеансы
```

## Конструктор формы

Форма разделена на два файла:

- `Form1.cs` — обработчики кнопок и методы программы;
- `Form1.Designer.cs` — описание расположения элементов управления, созданное в стиле конструктора Windows Forms.

Чтобы открыть визуальный конструктор, откройте `Form1.cs` в обозревателе решений и нажмите **Shift + F7** или выберите **«Просмотреть конструктор»** в контекстном меню файла. Элементы формы можно перемещать и изменять мышью.

## Использованные библиотеки

- **Vosk** — локальное распознавание речи. Русская модель распространяется отдельно; её лицензия и условия использования указаны на странице модели.
- **NAudio** — получение звука с микрофона.
- **System.Speech** — озвучивание текста установленным голосом Windows.

## Известные ограничения

- Небольшая модель Vosk рассчитана на работу на обычном компьютере, но точность зависит от качества микрофона, шума и дикции.
- Для работы распознавания требуется один раз загрузить модель.
- Для озвучивания должен быть установлен совместимый русский голос. Если список голосов пуст, программа покажет предупреждение.
- Программа рассчитана на Windows x64.


## Если Visual Studio сообщает о неизвестных сопоставлениях конфигурации

В решении используется стандартная платформа `Any CPU`. После обновления проекта:

1. Закройте Visual Studio.
2. Откройте именно файл `РечевойПомощник.sln`, а не отдельный `.csproj`.
3. Дождитесь завершения восстановления пакетов NuGet.
4. В меню «Сборка» выберите «Пересобрать решение».
5. Если запуск всё ещё не начинается, нажмите правой кнопкой мыши на проект «РечевойПомощник» в обозревателе решений и выберите «Назначить запускаемым проектом».
6. Для запуска нажмите F5.

В панели конфигурации сверху должна быть выбрана конфигурация `Debug` и платформа `Any CPU`.
